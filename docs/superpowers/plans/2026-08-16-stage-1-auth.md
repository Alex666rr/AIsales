# Stage 1 Access Control Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add provisioned organizations, tenant-safe roles, password authentication, mandatory TOTP, and revocable server-side sessions.

**Architecture:** Organization and user records live in the Stage 1 PostgreSQL schema. Services receive a trusted principal rather than a caller-provided role. Password/TOTP verification is separate from session issuance, and every security-relevant transition appends an audit event through the Stage 1 unit of work.

**Tech Stack:** Python, FastAPI, SQLAlchemy, Alembic, Pytest, PostgreSQL.

## Global Constraints

- No public user registration.
- Every user/resource access is organization-scoped and cross-tenant lookup is a neutral not found.
- Passwords and recovery codes are one-way hashed; TOTP secrets are encrypted and never returned.
- Privileged roles require completed TOTP before a session is issued.

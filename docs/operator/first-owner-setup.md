# Первый владелец AIsales

Этот шаг выполняется один раз для новой организации. Он создаёт организацию и
первого владельца, а затем выдаёт одноразовую ссылку настройки пароля и 2FA.

## Перед началом

- Используйте доверенный личный компьютер и браузер.
- Убедитесь, что Railway-развёртывание AIsales доступно.
- Откройте Railway → сервис **AIsales** → **Variables** и подготовьте значение
  `PLATFORM_OWNER_TOKEN`. Не копируйте его в чат, файлы или заметки.

## Запуск

В PowerShell из корня репозитория выполните:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\tools\provision_first_owner.ps1
```

Изменение политики действует только в текущем окне PowerShell. Скрипт спросит
название организации, рабочий email первого владельца и токен. Токен вводится
скрыто, не записывается в файл и используется только для HTTPS-запроса к AIsales.

Если AIsales развёрнут по другому адресу, укажите его явно:

```powershell
.\tools\provision_first_owner.ps1 -BaseUrl "https://ваш-домен"
```

Скрипт покажет одноразовую ссылку вида `/setup?token=...`. Откройте её сразу в
том же браузере. Ссылка действует 48 часов, используется один раз и даёт право
задать пароль, подключить TOTP и сохранить recovery-коды.

## После настройки

1. Сохраните recovery-коды в менеджере паролей.
2. Выйдите и выполните обычный вход через экран AIsales, чтобы проверить пароль
   и второй фактор.
3. Для остальных сотрудников используйте приглашения в веб-интерфейсе. Не
   передавайте им ссылку первичной настройки или токен владельца платформы.

## Если что-то пошло не так

Не запускайте процедуру повторно наугад, если ссылка утрачена или истекла:
сначала проверьте, был ли уже создан владелец, через журнал/базу платформы.
Для восстановления используйте отдельную административную процедуру, когда она
будет введена. Не отправляйте в поддержку токены, одноразовые ссылки,
recovery-коды или пароли.

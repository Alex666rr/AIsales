# Trello board AIsales

## Назначение

Доска Trello — личная карта проекта: она показывает, что готово, где остановилась работа и какой блок следующий. Исходный код и фактический статус релизов остаются в GitHub и Railway; Trello не хранит Telegram-сессии, пароли, ключи API или данные клиентов.

На доске шесть списков:

- `📍 Сейчас` — как читать доску и следующий блок;
- `✅ Stage 0` — завершённый Telegram-прототип;
- `🚧 Stage 1` — текущая инфраструктура продаж;
- `🗂 Stage 2` и `🗂 Stage 3` — последующие этапы;
- `📦 Архив` — вручную закрытые карточки.

Карточки имеют идентификаторы `S0.01`, `S1.03` и т.п. Внутри указаны статус, цель, следующий шаг и путь к полному плану в репозитории. В раздел `Заметки` можно писать вручную: синхронизация его сохранит.

## Локальная настройка

В локальном `.env` (он игнорируется Git) нужны только:

```env
TRELLO_API_KEY=
TRELLO_TOKEN=
TRELLO_BOARD_ID=
```

`TRELLO_TOKEN` — именно вручную сгенерированный Trello token с правами `read,write`, не OAuth Secret. Если token перестал работать, отзови его в Trello и создай новый; исходный код менять не нужно.

## Синхронизация доски

В PowerShell из корня проекта выполните:

```powershell
$values = @{}
Get-Content .env | ForEach-Object {
  if ($_ -match '^\s*([A-Za-z_][A-Za-z0-9_]*)\s*=\s*(.*)\s*$') {
    $values[$matches[1]] = $matches[2].Trim().Trim('"').Trim("'")
  }
}
$env:TRELLO_API_KEY = $values.TRELLO_API_KEY
$env:TRELLO_TOKEN = $values.TRELLO_TOKEN
$env:TRELLO_BOARD_ID = $values.TRELLO_BOARD_ID
python tools/trello/sync_board.py
```

Команда создаёт, если их ещё нет, шесть списков карты проекта и карточки задач всех Stage 0–3. Повторный запуск безопасен: новых дубликатов не появится и уже созданные карточки не будут изменены без смены их статуса в проекте.

Я запускаю синхронизацию после каждого завершённого блока работы и коммита. Это локальный процесс: токен не нужен GitHub Actions и Railway.

## Ручная работа в Trello

Можно свободно добавлять комментарии, чек-листы, участников, вложения и метки. Текст после заголовка `Заметки` синхронизация сохраняет. Не переименовывайте идентификатор в начале названия карточки (`S1.03` и т.п.), иначе система воспримет её как новую ручную карточку и создаст актуальную карточку плана отдельно.

## Безопасность

- Не прикрепляйте `.env` к карточке и не вставляйте token в комментарии.
- Не добавляйте `.env` в GitHub.
- Если token попал в публичное место, немедленно отзовите его в Trello и создайте новый.
- Команда запускается только на локальном компьютере; Railway её не запускает.
